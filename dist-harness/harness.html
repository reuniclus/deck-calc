Deck

others is derived, never stored — it absorbs every edit so the deck always totals exactly. Groups must be disjoint: a card belongs to exactly one.

Query

>= <= = > <, combined with & | ! and parentheses. A bare name means ≥1. any k of (…) works. Quote multi-word names. Also true / false.

The query is stored against groups, not spellings — rename a group and the query follows it. Delete a group it references and you get told, rather than silently getting different numbers.

Turns

Cards drawn below the starting hand size have no turn yet — they're still part of the opener.
